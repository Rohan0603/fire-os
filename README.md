# FIRE OS

Local-first FIRE planning dashboard for portfolio tracking, retirement
calculations, insurance, ESOPs, and guarded AI guidance.

Live app: <https://fire-os-dd6d6.web.app>

## Documentation

Read the canonical guide in [docs/README.md](docs/README.md). It covers setup,
architecture, APIs, authentication, Assistant deployment, testing, and common
troubleshooting. Release history is in [docs/CHANGELOG.md](docs/CHANGELOG.md).

## Quick start

```bash
npm ci
npm run dev
```

Open the URL printed by Vite. Guest mode works locally; Firebase credentials
are required for authentication and cloud sync.
